⚙️ Configuración inicial (una sola vez)

Para conectar Gmail necesitas crear credenciales en Google Cloud. Sigue estos pasos:

1
Ve a Google Cloud Console
console.cloud.google.com → Crea un proyecto nuevo → Llámalo "CICSA"
2
Habilita la Gmail API
APIs & Services → Enable APIs → busca "Gmail API" → Enable
3
Crea credenciales OAuth
APIs & Services → Credentials → Create Credentials → OAuth Client ID → Desktop App → Descarga el JSON
4
Genera el token con generar_token_gmail.py
Guarda el JSON descargado como gmail_credentials.json junto a ese script (en el repo) y corre python3 generar_token_gmail.py — abre el navegador para autorizar y crea gmail_token.json con el resultado.
5
Configura la variable en Railway
Copia el contenido completo de gmail_token.json a la variable GMAIL_TOKEN en Railway → Variables → Guardar. Railway redeploya solo y Gmail queda conectado.
🧹 Limpieza de datos — qué le falta al balance para ser real
👯 El mismo registro guardado en dos semanas
No son dos capturas parecidas: es el mismo registro, con el mismo id, guardado en más de una semana. Cuenta doble en todo —presupuesto, saldo, conciliación— y hasta ahora era invisible, porque ninguna pantalla mostraba en qué semana vive cada renglón: en la lista se ven dos filas idénticas y parecen dos capturas distintas. Ábrelo en Gastos y borra la copia sobrante; queda una sola.

💲 Importes que no cuadran con el CFDI
El folio del gasto casa con un comprobante timbrado, pero el importe capturado es otro. Suele ser que se tomó el subtotal en vez del total, o que la lectura leyó mal una cifra. El del CFDI es el bueno.
🚫 Complementos de pago registrados como gasto
Un complemento de pago no es un gasto: es el acuse de que se pagaron facturas que ya estaban registradas. Capturarlo cuenta el mismo dinero dos veces. El PDF engaña porque muestra un monto grande en “Monto de pago”, aunque el comprobante va con Subtotal 0 y Total 0.
📅 Gastos con fecha dudosa
El presupuesto se reparte por fecha, así que un gasto mal fechado descuadra dos semanas: le sobra a una y le falta a la otra. Aquí salen los que casi seguro quedaron con la fecha equivocada. Escribe la fecha correcta en la última columna y aprieta Guardar: el gasto se va solo a la semana que le toca. Cuando el campo viene en verde, ya trae la fecha buena tomada del CFDI y solo hay que confirmarla.

🧹 Revisar facturas duplicadas

Estas facturas parecen estar contadas dos veces: el formato viejo de divididas guardaba la factura padre "Dividida" y además cada categoría como gasto aparte, y también hay capturas repetidas. El registro marcado en naranja es el que se sugiere borrar. Revisa cada grupo antes de borrar — nada se borra solo.

🧹 Revisar alias sospechosos

Estos aliases parecen ser de otro producto (fusiones erróneas del emparejado difuso viejo). Quitar un alias hace que, la próxima vez que leas esa factura, ese producto se registre por sí solo. Revisa cada uno — quita solo los que de verdad no correspondan.

📦 Producto comercial

① Qué es
Escribe un solo nombre principal, sin comas ni puntos separando variantes. Es la palabra con la que Menú conecta este precio a tus recetas. Si pegas varios nombres, Egresos moverá los demás a “Otras formas” al guardar. Déjalo vacío si este producto no va a Menú.
Plurales o variantes con calificativo: “tortillas de maíz”, “Ajo picado”. Cada una conecta con este mismo precio. Mayúsculas y acentos no hace falta ponerlos — esos ya se conectan solos.
② Cuánto costó
El total del paquete/bolsa completo, no por unidad. Normalmente se llena solo al procesar la factura.
③ Cómo se costea en Menú
Suma todo lo que trae la presentación. Ej: una caja de 16 botellas de 1 litro son 16 lt.
No hace falta el peso — algo que se cuenta por pieza (pan, huevo) no lo necesita.
% que se desperdicia (hueso, cáscara, descongelado)

🔗 Faltantes de Menú

Sube el CSV que exporta Menú con los ingredientes que se quedaron sin precio. Muchos ya tienen precio en el catálogo con otro nombre —«Aceite» existe como «Aceite vegetal»— y eso se arregla agregando el sinónimo, sin capturar ningún precio nuevo.

🍽️ Sincronizar validados a Menú

Cada producto se envía como precio por kg (o litro), ya descontando su % de merma — CICSA Menú no aplica ningún ajuste propio, así que este es el precio final que va a usar para costear recetas.
